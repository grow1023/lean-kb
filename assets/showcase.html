lean-kbWhy use it · 0.1.0

lean-kb

A Claude Code hook and skill that adds nine knowledge-base design rules to the context when a prompt names a wiki, an ontology, or a RAG index.

01

The rules arrive when the task starts

The hook reads each prompt. If it names a wiki, an ontology, a knowledge graph, a RAG index, or a memory index, the hook adds a nine-rule note to the context. For other prompts it prints nothing.

02

Each rule shows its evidence and its limits

SKILL.md has one table row for each rule: the result in the talk, the scope, and a status. Two of the nine rules are marked as inference. The gate fails when a document states a measured number that is not in evidence/facts.md.

03

Small, local, and easy to turn off

The hook uses only the Python standard library. It uses no network, writes no file, and does not log the prompt. It always exits with code 0. One environment variable or one flag file turns it off.

lean-kbHow it works · 0.1.0

How it works

One prompt passes three stages. The hook runs locally before the model reads the prompt. It makes no network call.

01

1. Read the prompt

Claude Code starts the hook for each submitted prompt and passes the prompt as JSON on standard input. If a disable switch is on, or the input is not valid JSON, the hook prints nothing.

02

2. Match the keywords

The hook removes URLs and then looks for a keyword such as wiki, ontology, knowledge graph, RAG, or MEMORY.md. A Latin keyword must be a full word, so the word storage does not match RAG.

03

3. Add the note

On a match, the hook prints the text of rules/lean-kb.md as additional context. The model reads the nine rules with the prompt. The note points to SKILL.md for the evidence and the templates.
